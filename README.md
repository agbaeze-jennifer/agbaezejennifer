# Agbaeze Jennifer | Portfolio
Hi, I'm **Agbaeze Jennifer**, a web developer and Computer Science student at Michael Okpara University Of Agriculture, working towards becoming a creative technologist.

This is my personal portfolio website. I built it to show who I am, what I can build, and how to reach me. I wanted it to feel alive, not like an ordinary website.

**Live site:** https://agbaezejennifer.vercel.app

## Features

- Animated hero with a typing role effect and a photo that tilts with the mouse
- Scroll-driven About statement, skills cards and process timeline
- Filterable project cards
- Working contact form (Web3Forms)
- Responsive on all screen sizes, with reduced-motion support

## Built with

HTML, CSS and vanilla JavaScript. Fonts: Barlow Condensed and Manrope. Hosted on Vercel.

## Run locally

Open `index.html` in a browser, or use the VS Code Live Server extension. Nothing to install.

## Edit

- **Projects:** the `projects` list at the top of `js/main.js`
- **Colours:** the variables at the top of `css/style.css`
- **Contact details and skills:** `index.html`
